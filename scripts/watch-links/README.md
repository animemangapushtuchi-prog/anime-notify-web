# 配信サービスの作品ページへのリンクを集める（2026-10-19 作成）

作品の公式サイトに載っている「各配信サービスの作品ページ」へのリンクを集め、配信データの `watchUrl` に入れる手順。
配信一覧のアイコン（↗）と作品ページの「開く ›」の行き先になる。**推測でURLを作らない**（公式サイトに載っていたリンクだけ）。

作業フォルダ（どこでもよい）で順に実行する。季節は各スクリプトの `2026-fall` を書き換える。

1. `node <repo>/scripts/watch-links/1-collect.mjs` … 公開中の作品の公式サイトを読み、サービスごとにリンクが1つに決まるものを `watch_fall.json` へ（書き込みなし）
2. `node <repo>/scripts/watch-links/2-verify.mjs` … リンク先のページタイトルに作品名が含まれるかを確認し `watch_verify.json` へ。
   `mismatch`（別作品・前シーズンのページ）は使わない。目で見て正しければ追加ファイルに入れる
3. `node <repo>/scripts/watch-links/3-apply.js [追加.json] --write` … 管理用・公開用の行に `watchUrl` を書き、公開まとめ文書を作り直す（Firebase CLI のログインが必要）

- 自動の読み取りを断っているサイト（例：薬屋のひとりごと）は、ブラウザで公式サイトを開いてリンクを取り出し、追加ファイルで渡す
- 2026-10-19 の結果：750行中 175行（33作品）にリンク。別作品・前シーズンのページを指していた12件は除外

## 配信サービス側の一覧から補う（2026-10-23）

公式サイトにリンクが無い作品は、配信サービス自身の一覧・検索から、作品名が一致する作品ページを探して補った。
照合は「表記ゆれ（全角半角・空白・記号・【オンエア版】などの飾り・Season2/第2期/シーズン2）をそろえて一致」かつ
「期数（クール数）が一致、または期数の無いシリーズのページ」。候補が2つ以上あるものは使わない（例：生徒会にも穴はある！の TV放送版／規制解除版）。

- dアニメストア：季節ページ `animestore.docomo.ne.jp/animestore/CF/{fall など}`（画面をJSで描くのでブラウザで開いて workId と作品名を取り出す）。
  ここに載っている＝dアニメ自身がその季節のラインナップとしている作品ページなので、1期と同じページ（薬屋のひとりごと等）でも使ってよい。44行中36行
- U-NEXT：`video.unext.jp/freeword?query=作品名` を作品ごとに開き、結果の `/title/SIDxxxxxxx` と作品名を照合（ブラウザの同じ画面内で iframe を使って順に読んだ）。55行中47行
- ABEMA の検索は続けて使うと止められるので使っていない
- 2026-10-23 時点：750行中258行に作品ページのリンク。リンクが無い行は「検索 ›」（検索結果へ）で補っている

## robots.txt の確認（2026-10-27）

- dアニメストア：`/animestore/sch`・`/animestore/sch_pc`（検索）は Disallow → **まとめて検索する収集には使わない**。季節ページ（`/animestore/CF/...`）は可
- DMM TV：`/vod/list/*keyword=*`（検索）は Disallow → 収集には使わない
- U-NEXT：`/freeword` は禁止されていない → 人気作の照合に使用（ブラウザの同じ画面で iframe を順に読む）
- 利用者が押す「検索 ›」リンクは、人がブラウザで開くものなので対象外
